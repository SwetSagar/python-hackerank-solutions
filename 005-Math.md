# Math

## Polar Coordinates

```

import cmath
complex_input = complex(input())
print(abs(complex_input))
print(cmath.phase(complex_input))

```

## Mod Divmod

```
a = int(input())
b = int(input())
print(a//b)
print(a%b)
print(divmod(a,b))

```


## Power - Mod Power 

```
a = int(input())
b = int(input())
m = int(input())
print(pow(a,b))
print(pow(a,b,m))

```

## Integers comes in all sizes

```

a = int(input())

print(pow(a,b)+pow(c,d))

```
